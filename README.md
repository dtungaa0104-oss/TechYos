# ТехЁс

Мэдээллийн технологи ба Иргэний ёс зүйн боловсролын 6–12-р ангийн цахим орчин: хөтөлбөр, нэгж ба ээлжит хичээлийн төлөвлөгөө (Word татах, хэвлэх), сорил, ажлын хуудас, 3D лаб, тоглоом, шивэх дасгал, кэйс, эцэг эхийн хэсэг.

## Render дээр байршуулах
1. render.com руу GitHub бүртгэлээрээ нэвтэрнэ.
2. **New → Blueprint** сонгоод энэ репог (TechYos) сонгоно. `render.yaml` файлыг Render өөрөө уншина.
3. **Apply** дарна. Хэдэн секундын дараа `https://techyos.onrender.com` маягийн хаяг гарна.

Сайт нь нэг `index.html` файлтай статик сайт тул сервер, өгөгдлийн сан шаардлагагүй.
