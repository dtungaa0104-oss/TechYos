# ТехЁс

Мэдээллийн технологи ба Иргэний ёс зүйн боловсролын 6–12-р ангийн цахим орчин: хөтөлбөр, нэгж ба ээлжит хичээлийн төлөвлөгөө (Word татах, хэвлэх), сорил, ажлын хуудас, 3D лаб, тоглоом, шивэх дасгал, кейс, эцэг эхийн хэсэг.

## Render дээр байршуулах
1. render.com руу GitHub бүртгэлээрээ нэвтэрнэ.
2. **New → Blueprint** сонгоод энэ репог (TechYos) сонгоно. `render.yaml` файлыг Render өөрөө уншина.
3. **Apply** дарна. Хэдэн секундын дараа `https://techyos.onrender.com` маягийн хаяг гарна.

Сайт нь нэг `index.html` файлтай статик сайт.

## Сурагчдын дүн цуглуулах сервер (`server/`)
«Миний анги» хэсэг (багшийн самбар, сорилын дүн, програмчлалын явц) `techyos-api` сервер болон Postgres өгөгдлийн сантай ажиллана.

1. **Neon** (neon.com) дээр үнэгүй бүртгэл нээж, шинэ төсөл (project) үүсгэнэ. **Connection string**-ийг (`postgresql://...`) хуулна.
2. Render дээр `techyos-api` web service үүсгэнэ (Blueprint ашигласан бол автоматаар санал болгоно; гараар бол **New → Web Service**, энэ репо, Root Directory: `server`, Build: `npm install`, Start: `node index.js`, Instance: Free).
3. **Environment** хэсэгт `DATABASE_URL` = Neon-ы connection string гэж нэмнэ.
4. Сервер `https://techyos-s3w1.onrender.com` хаягтай ажиллаж байна (`index.src.html` доторх `API_DEF`).

Сервер анх асахдаа хүснэгтүүдээ өөрөө үүсгэнэ. Үнэгүй багцад 15 минут хандалтгүй бол унтаж, дараагийн хүсэлтэд ≈1 минутын дотор асна.
